# 煤矿机器人作业大脑 Mock 演示

访问 `/mining-brain` 后，页面保持等待指令，不会自动执行。输入默认指令“开始钻锚作业”，点击“发送指令”或按 Enter：

1. 指令交互：记录并确认自然语言指令。
2. 意图理解：识别为“执行钻锚备料流程”。
3. 作业规划：生成钻杆、锚固剂、锚杆 3 个父任务及 9 个子任务。
4. 任务执行：依次完成检测、抓取和上料；同步更新双相机、任务树、Three.js、FR3 遥测、设备状态和日志。
5. 作业完成：9 个子任务全部完成并显示成功结果。

支持暂停、继续、取消、重置、0.5×/1×/2×速度，以及“模拟故障”。模拟故障会令 MoveIt 2 进入 ERROR，当前任务失败；重置后可重新演示。

Mock 业务状态只由 `src/mining/dataSource.ts` 的 `MiningMockDataSource` 产生，各组件没有独立业务定时器。
